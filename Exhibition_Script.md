# Exhibition demonstration — 4 minutes
0:00–0:40: Our project NaviSkill addresses PS2 under Digital Bharat for Inclusive Learning. People may have smartphones but lack confidence with everyday digital tasks. Our goal is safe, practical, multilingual learning.
0:40–1:30: Switch language; open Practice and the Virtual Digital City. Select Digital Bank or Railway Station. Demonstrate Learn, Practise, Check, Complete using fictional details only.
1:30–2:15: Show Scam Detective and Smart Scam Shield using the built-in sample. Explain warning signs are not a guarantee. Ask NaviAI an offline question, then optionally demonstrate online AI on the configured site. Explain the API key stays on the server.
2:15–3:15: Show the roadmap, quiz and progress. Create a clearly labelled demonstration learner, record a training session and show Skill Passport and assessment dashboard. Do not present demonstration records as real impact; delete them afterward.
3:15–4:00: Explain accessibility, offline backup, local privacy and SDG 4/10 alignment. Mention limitations: local records, optional internet AI, need for actual community evaluation. Close: NaviSkill helps learners practise before performing real tasks.
Backup: standalone HTML, no network needed for core tasks; use typed input if microphone unavailable.
