# Security review — V15
Scope: source review and mocked endpoint tests, not an independent penetration test.

Controls: server-only Gemini key, constant-time comparison for equal-length access codes, POST/JSON validation, 8 KB body and 1,000 character question limits, language/mode allowlists, same-host origin check when supplied, 12-second upstream timeout, bounded output, generic backend errors, no-store. Added failed-code throttling, identifier heuristic including Devanagari digits, framing protection, MIME sniffing protection, referrer policy and restricted service worker cache. Community records are validated and rendered using text nodes. AI output is displayed as text. No real payments or government submissions.

Residual risks: inline scripts/styles require unsafe-inline CSP; legacy HTML rendering has not been exhaustively proven XSS-free. Rate limits are per instance and apparent IP, not distributed or reliable identity; use Vercel firewall/distributed limits and provider quota controls before public rollout. Shared code is not individual authentication. Local records are unencrypted and editable, not certified or tamper-proof; avoid personal identifiers and clear demo records. Identifier filtering is heuristic. Online prompts go to Google after consent; speech recognition may use browser-provider servers. AI and scam heuristics can be wrong. No live security scan, live provider test or hosted header verification performed here. Rotate access code after exhibition; never commit secrets.
